closure sends no execution signal. Final exact-candidate review and integration
remain the coordinator gate; P06 starts only after verified P05 integration.

## Implemented contract

The registered native SSE route validates canonical lossless cursors through
SQLite's signed maximum, validates both cursor fields, and gives a valid
Last-Event-ID precedence. Short bounded reads end before delivery. Browser cookies
are required; reporter/pairing bearers cannot subscribe. Twenty admitted streams,
a 1 MiB byte ceiling, independent five-second stalled-drain deadline and blocked
session revalidation bound its lifecycle.

One workspace subscription owns replay, fallback and visible freshness refresh.
Recovery retains safe replay obligations, refreshes active snapshots, invalidates
retained queries and rebases supported resets before reconnecting. Generation and
auth repair retain mounted drafts and frozen retry identity. Old command receipts
cannot advance replay or replace a newer cached version.

Additive tracking DTOs preserve command/task/run contracts and batch latest
attempts without per-card fetches. Server-filtered Activity excludes heartbeat
noise while raw sequence history retains it. Closure facts remain distinct from
producer events. Agents, direct/embedded attempts and the board use reported
freshness and explicit uncertainty, separately from browser connection state.
The visible 15-second refresh updates freshness and Overview without a new write.
