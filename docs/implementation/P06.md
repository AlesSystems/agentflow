separate. There is no provider installation, process launch, stop, scheduling,

two agents, an implementation attempt, and a separate verification attempt on the

## Preserve the delivery contracts

The outbox lives outside service data. Public typed `/settings` binds its real
location and current generation; explicit configuration must agree. Root/directory
pins, permissions, canonical overlap, symlinks, nonregular files, headers and typed
responses fail closed. Original parsed JSON survives validation transforms.
Registration keys, event IDs/times/sequences/envelopes/digests remain immutable.

Stable SQLite OS-held publication and delivery locks never use PID as authority.
Descriptor publication, file/directory fsync, acknowledged watermarks and cleanup
retain crash recovery. Every actual publication acquisition performs full recovery,
contiguous coverage/identity/security checks, current logical file lengths and
outstanding peak reservations, including an already-open owner after another crash.
Quota is 10 MiB/run and 100 MiB/global in owned logical regular-file lengths,
including metadata, sidecars, damaged files and transient copies. Filesystem
allocated-block and directory overhead are excluded. Lock bootstrap reserves 64 KiB.

Global event selection and existing successor-cursor durability share one owner,
then HTTP occurs outside it. Empty/plain/targeted selection does not write the
cursor. Registrations retain their existing dependency path. Every same-value
cursor publication still uses full atomic admission and fsync. No cross-owner cache,
second storage engine, migration, dependency, public schema or budget change exists.

Each invocation retains its five-second retry budget and 500 ms turns. Only native
admission/wait expiry with durable pending work yields queued 2. Actual recovery,
cursor, rollback or noncontention SQLite I/O remains local 1; corruption and security
retain failure semantics. Precedence remains 1, then 3, then 2, then 0. ACK completion
is observed after durable watermark/cleanup under that owner; later enqueues remain
future work. Current-generation and restored-prefix checks never clear, remap,
resequence or synthesize missing records. Reporter cannot complete/reopen/close.
