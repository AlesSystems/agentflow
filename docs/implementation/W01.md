## Implemented contract and operation

Migration 0006 is additive; migrations 0000–0005 retain their original bytes.
Publication validates same-project task references and a DAG of at most 100 nodes
and 200 edges. Each revision preserves its original labels, edges and links.
Attempts bind one immutable revision and use a separate durable registration
ordinal. The native active index permits one queued/running attempt per workflow.
Events, append-only node history, projection, original ACK and changes commit in
the existing immediate SQLite transaction. Authentication and identity validation
precede disclosure; exact retries resolve before later mutable state checks.

Publish workflow → revision → attempt, then report start and observations through
the [CLI](../CLI.md#reported-workflows) or [public API](../API.md#reported-workflow-plans-w01).
Offline registration preserves this dependency order. A rejected prefix remains
pending and byte-identical while eligible unrelated producers continue. Typed
workflow producers use `workflow-runs/<UUID>`; task producers keep their legacy
UUID leaves. Same-UUID producers have independent sequence, cursor and ACK
authority, while both kinds participate in native leases, reservations, recovery,
fairness and the unchanged 10 MiB producer / 100 MiB global limits. Keep blocked
outboxes intact; registration replay cannot reset an allocated sequence. Restore
cannot recover history absent from both the restored database and retained local
authority. No PID-based lock reclamation or reply-cap relaxation was added.

Only task creation requests the narrow `Prefer: return=minimal` representation.
Its bounded metadata projects the original full receipt, preserving original
status, versions, cursor and body generation. Default/full API replies, current
GET detail and full event ACKs retain their distinct meanings. The CLI accepts a
strict compact or valid bounded legacy full response. An oversized old-server
full reply stays blocked until a compatible service upgrade; original queued
body/key/digest remain unchanged. Generated task UUID validation checks shape and
known bindings, not arbitrary valid-ID substitution from the request alone.

The browser uses the existing shared SSE/poll owner. Workflow, linked-attempt
freshness and browser connection remain separate. Real silence updates staleness
through the visible refresh without another write. Missing node observations,
linked attempts and skill fields remain Unknown, including after workflow success.
Skill source/version are escaped inert text. Current and historical evidence links
retain their original task/attempt identity; plan-only task links require no
fabricated workflow attempt. Valid uppercase route UUIDs are canonicalized.
Local task/run return context restores selection and node focus without refresh
stealing focus.

Graph drag/connect/reconnect/delete and the interactivity toggle are disabled.
Keyboard selection, Enter/Space/Escape, zoom and evidence links remain usable.
Nodes use stable 230×104 geometry. New controls and the board's Projects breadcrumb
have 44px targets. Reduced-motion checks use actual browser behavior. The graph
does not launch or control a harness; reports never complete tasks. Human-only
stale tracking closure records interrupted/reason without refreshing the report
time, stopping a process or replacing human task acceptance.
